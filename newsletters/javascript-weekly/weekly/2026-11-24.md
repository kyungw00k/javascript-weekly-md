> JavaScript Weekly — Issue #812

## Top Stories

![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/zeicnfyzbo9kgkkmmgwf.jpg)

[Nudeps: Bundler-Like Imports, None of the Baggage](https://lea.verou.me/blog/2026/nudeps/) — What if you could `npm install` a package and import it by name in the browser without a bundler? Lea and Dmitry Sharabin's new tool makes this easier than ever using import maps (which it keeps up to date). Run `npx nudeps install` and add the import map script to your HTML. There are also [demos](https://nudeps.dev/demos/) to try.

Lea Verou

💡 This work follows on from Lea's popular essay earlier this year: [Web Dependencies are Broken. Can We Fix Them?](https://lea.verou.me/blog/2026/web-deps/)
