## Top Stories

![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/jgkycdtzpabaibtigxfp.jpg)

[Bun 1.4: Now More Node.js Compatible Than Ever](https://bun.com/blog/bun-v1.4) — Several weeks after it was initially expected to launch, Bun's [big AI-powered rewrite from Zig to Rust](https://bun.com/blog/bun-in-rust) is here, complete with traditional [▶️ release video](https://www.youtube.com/watch?v=i38DgEuaJwM). A lot of effort has been put into compatibility, not just with Node, but Next.js, Playwright, Vitest, and Nuxt too. Throughput and CPU/memory usage also see huge improvements.

The Bun Team

[Solid 2.0 RC: The Big <Reveal>](https://www.solidjs.com/blog/solid-2-0-rc-the-big-reveal) — Async now lives in the reactive graph, so async data flows through ordinary memos. `createResource`, `batch` and `startTransition` are gone. SolidStart gets retired into a `start: true` flag on the Vite plugin, and the API is now frozen.

Ryan Carniato

## 📖 Articles and Videos

[The Wicked Reason Removing Code Beats Better Scheduling](https://infrequently.org/2026/08/notes-on-performance-remediation-strategies/) — A lot of performance work goes into shuffling when things load, when the bigger win is usually not sending the code at all. Alex Russell makes the case that this is a management problem more than a technical one.

Alex Russell

[ESM and CommonJS: What `import` and `require` Actually Do](https://blog.gaborkoos.com/posts/2026-08-14-Your-Modules-Are-Lying-to-You/) — They look like the same operation, but Gabor shows how an ESM `import` stays wired to the exporter's binding, while a destructured `require()` only holds a *copy*. The consequences show up in circular dependencies and published packages.

Gabor Koos
