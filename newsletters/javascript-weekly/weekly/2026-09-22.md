# JavaScript desktop apps in under 10MB

> JavaScript Weekly — Issue #803

## Top Stories

![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/l5ejacd7rpbkelmaxdto.jpg)

[tinyjs: Build JavaScript Desktop Apps in <10MB](https://tinyjs.app/) — I built an app with this and was impressed. You get a [txiki.js](https://github.com/saghul/txiki.js/)-powered backend with full system access (including FFI!), native webview rendering, and tiny macOS, Linux, and Windows builds. It even makes it easy to sign/notarize the final app.

Tarwin Stroh-Spijer

There are lots of great options in this space though:

- [Electrobun](https://blackboard.sh/electrobun/) offers richer multi-window and GPU features, at the cost of a larger TypeScript runtime – though it can instead use Zig, Rust, Go, or Odin for a tiny native main process.
- [Perry](https://www.perryts.com/) is a TypeScript to native AOT compiler whose primary UI model renders AppKit, Win32 and GTK4 widgets for a more conventionally native feel.
- [Electron](https://www.electronjs.org/) and the experimental [Deno Desktop](https://deno.com/blog/v2.9#deno-desktop) are powerful, but their executables typically run several times larger.
- [Neutralinojs](https://neutralino.js.org/) apps can be even smaller than tinyjs's, but you lose the general-purpose JavaScript privileged backend by design.
