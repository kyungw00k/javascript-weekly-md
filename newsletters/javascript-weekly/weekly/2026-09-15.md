[Modern Web Types: TypeScript Support for Newer Web APIs](https://philipwalton.com/articles/modern-web-types/) — TypeScript's DOM types only include APIs shipped in *multiple* browser engines, so things like element-scoped `startViewTransition` and `fetchLater` throw up errors. [modern-web-types](https://github.com/philipwalton/modern-web-types) is a drop-in `lib.dom` replacement that adds missing interfaces/members shipped in any single browser engine.

Philip Walton (Google)

[React 19.3 Released](https://react.dev/blog/2026/09/09/react-19-3) — A significant minor release making view transitions and Fragment Refs stable, adding Trusted Types support, and more. We covered it in more depth in [last week's *React Status*](https://react.statuscode.com/issues/490).

**IN BRIEF:**

- 🔒 Attackers are [scanning for exposed Vite dev servers](https://www.f5.com/labs/articles/cloud-takeover-mass-scanning-for-exposed-vite-endpoints-cve-2026-39364) exploiting a `server.fs.deny` bypass (patched in Vite 7.3.2 and 8.0.5 earlier this year) to grab credentials from `.env` files. Vite listens on localhost by default, but double check your setup.
- [Safari 27](https://developer.apple.com/documentation/safari-release-notes/safari-27-release-notes) shipped yesterday (alongside macOS/iOS 27), bringing the module loader rewrite [we covered last week](https://webkit.org/blog/18227/fixing-top-level-await-in-safari/), so top-level `await` now works reliably in all major browsers.
- TC39 meets in Tokyo in two weeks. [Here's the agenda](https://github.com/tc39/agendas/blob/main/2026/09.md) with three iterator helper follow-ups ([join](https://github.com/tc39/proposal-iterator-join), [includes](https://github.com/tc39/proposal-iterator-includes) and [chunking](https://github.com/tc39/proposal-iterator-chunking)) all up for Stage 4, plus more.
- 🔒 Starting this Thursday, [the OpenJS Foundation's CVE team is taking a break](https://openjsf.org/blog/the-openjs-foundation-cna-is-taking-a-coordinated-break) till October 6 due to burnout driven by a surge of AI-generated reports. Actively exploited issues will still get a response.
- 🔒 [npm now places a temporary 72-hour 'security hold'](https://github.blog/changelog/2026-09-09-npm-extends-recovery-code-security-holds-to-all-accounts/) on *any* account after a successful recovery-code sign-in.

**RELEASES:**

- [pnpm 12.4](https://pnpm.io/blog/releases/12.4) – The package manager can now manage Rust crates and Python packages alongside npm ones in a single workspace.
- [Playwright 1.63](https://github.com/microsoft/playwright/releases/tag/v1.63.0) – Tests can now declare a named `lock` so those sharing a resource never run concurrently.
- [Node.js v26.8.2 (Current)](https://nodejs.org/en/blog/release/v26.8.2) and [v24.21.0 (LTS)](https://nodejs.org/en/blog/release/v24.21.0) – Both include a security release of Undici to fix numerous vulnerabilities.
