[Structs: TC39's Shared Structs Proposal, But Usable Today](https://structs.arv.tools/) — A former TC39 delegate's implementation of the Stage 2 [structs proposal](https://github.com/tc39/proposal-structs). The idea is you get shared memory between workers, so threads can work on the same objects instead of serializing copies back and forth. There's a [playground](https://structs.arv.tools/playground/) too.

[Introducing TanStack Redact: A Slimmer React Runtime](https://tanstack.com/blog/introducing-tanstack-redact) — A build plugin swaps React and React DOM for a smaller reimplementation in the browser with no code changes. It works with Vite, Start, Vinext and Next.js, and while TanStack reports 20-70% smaller client builds, rendering is *synchronous only*.
